# Football Telegram Bot — MongoDB

Telegram-бот для записи на футбольную игру в группе.

## Что умеет

- Создание игры админом прямо в группе.
- Запрет создания игры в личке с ботом.
- Кнопки `Буду` / `Не буду`.
- Лимит игроков по формуле `команды × игроков в команде`.
- Автоматический резерв, если мест нет.
- Автоматическое продвижение первого из резерва, если кто-то отказался.
- После 00:00 бот открывает добавление друзей, если основной состав не набран.
- До 3 друзей от одного участника.
- Запрет добавления друзей до 00:00 дня игры.
- Отмена своего добавленного друга через кнопку `Отменить друга`.
- Админское меню управления игрой.
- Отмена игры.
- Изменение даты, времени, цены, количества команд и игроков в команде.
- Закрытие и открытие записи вручную.
- Пересчет основного состава и резерва после изменения лимита игроков.
- Сбор подтверждений оплаты после игры.
- Хранение данных в MongoDB.

## Стек

- Python 3.12
- aiogram 3
- MongoDB
- PyMongo AsyncMongoClient
- APScheduler
- Docker Compose

## Быстрый запуск

```bash
cp .env.example .env
```

Открой `.env` и укажи:

```env
BOT_TOKEN=telegram_bot_token
ADMIN_TELEGRAM_IDS=123456789
```

Запуск:

```bash
docker compose up --build
```

## Как получить BOT_TOKEN

1. Открой Telegram.
2. Найди `@BotFather`.
3. Создай бота командой `/newbot`.
4. Скопируй токен в `.env`.

## Как узнать свой Telegram ID

Можно написать боту `@userinfobot` или временно залогировать `message.from_user.id`.

## Как использовать

1. Добавь бота в Telegram-группу.
2. Добавь ID админа в `.env`.
3. Запусти бота.
4. В группе напиши команду создания игры.

## Команды

### Создать игру

```text
/new_game 2026-06-12 20:00 3 6 200
```

Формат:

```text
/new_game YYYY-MM-DD HH:MM teams_count players_per_team price
```

Пример:

```text
/new_game 2026-06-12 20:00 3 6 200
```

Это значит:

- дата: 12.06.2026
- время: 20:00
- 3 команды
- по 6 игроков
- всего 18 мест
- цена 200 грн

Создавать игру можно только в группе. В личке бот откажет.

### Админское меню

```text
/game_settings
```

Открывает кнопки:

- `Открыть друзей`
- `Закрыть запись` / `Открыть запись`
- `Начать сбор оплат`
- `Отменить игру`

### Обновить сообщение игры

```text
/current_game
```

### Открыть друзей вручную

```text
/open_friends
```

### Закрыть запись

```text
/close_registration
```

После этого кнопка `Буду` отключается.

### Открыть запись обратно

```text
/open_registration
```

### Отменить игру

```text
/cancel_game
```

Можно указать причину:

```text
/cancel_game не набралось людей
```

После отмены кнопки записи отключаются.

### Изменить дату и время

```text
/edit_date 2026-06-19 20:00
```

### Изменить цену

```text
/edit_price 250
```

### Изменить количество команд

```text
/edit_teams 3
```

### Изменить игроков в команде

```text
/edit_players 7
```

После изменения формата бот пересчитывает лимит:

```text
max_players = teams_count * players_per_team
```

Первые по очереди становятся основным составом, остальные уходят в резерв.

### Запустить сбор оплат

```text
/payments
```

или

```text
/finish_game
```

## Основная логика

До 00:00 записываются только участники группы.

После 00:00, если основной состав не набран, бот открывает кнопку `Добавить друга`.

До 00:00 добавить друга нельзя даже если пользователь вручную нажмет старую inline-кнопку или остался в FSM-сценарии ввода имени.

Один участник может добавить максимум 3 друзей.

Добавленного друга можно отменить через кнопку `Отменить друга`. Бот покажет список только тех друзей, которых добавил именно этот участник.

Если основной состав заполнен, новые участники попадают в резерв.

Если кто-то нажал `Не буду`, первый игрок из резерва автоматически попадает в основной состав.

Если админ уменьшил лимит игроков, лишние участники из основного состава переходят в резерв по очереди записи.

Если админ увеличил лимит игроков, первые из резерва переходят в основной состав.

## Коллекции MongoDB

### users

Пользователи Telegram.

### games

Игры.

### participants

Участники игры: игроки и друзья.

### payments

Оплаты за игру.

## Важно

Бот использует polling, поэтому webhook не нужен.

Для продакшена можно заменить polling на webhook, но для MVP и закрытой футбольной группы polling проще.
