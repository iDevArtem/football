# Football Telegram Bot — MongoDB

Telegram-бот для записи на футбольную игру в группе.

## Что умеет

- Создание игры админом прямо в группе.
- Запрет создания игры в личке с ботом.
- Кнопки `Буду` / `Не буду`.
- Лимит игроков по формуле `команды × игроков в команде`.
- Автоматический резерв, если мест нет.
- Автоматическое продвижение первого из резерва, если кто-то отказался.
- После 00:00 бот открывает добавление друзей, если основной состав не набран.
- До 3 друзей от одного участника.
- Запрет добавления друзей до 00:00 дня игры.
- Отмена своего добавленного друга через кнопку `Отменить друга`.
- Админское меню управления игрой.
- Отмена игры.
- Изменение даты, времени, цены, количества команд и игроков в команде.
- Закрытие и открытие записи вручную.
- Пересчет основного состава и резерва после изменения лимита игроков.
- Сбор подтверждений оплаты после игры.
- Хранение данных в MongoDB.

## Стек

- Python 3.12
- aiogram 3
- MongoDB
- PyMongo AsyncMongoClient
- APScheduler
- Docker Compose

## Быстрый запуск

```bash
cp .env.example .env
```

Открой `.env` и укажи:

```env
BOT_TOKEN=telegram_bot_token
ADMIN_TELEGRAM_IDS=123456789
```

Запуск:

```bash
docker compose up --build
```

## Как получить BOT_TOKEN

1. Открой Telegram.
2. Найди `@BotFather`.
3. Создай бота командой `/newbot`.
4. Скопируй токен в `.env`.

## Как узнать свой Telegram ID

Можно написать боту `@userinfobot` или временно залогировать `message.from_user.id`.

## Как использовать

1. Добавь бота в Telegram-группу.
2. Добавь ID админа в `.env`.
3. Запусти бота.
4. В группе напиши команду создания игры.

## Команды

### Создать игру

```text
/new_game 2026-06-12 20:00 3 6 200 90 6
```

Формат:

```text
/new_game YYYY-MM-DD HH:MM teams_count players_per_team price duration_minutes friends_open_after_hours
```

Пример:

```text
/new_game 2026-06-12 20:00 3 6 200 90 6
```

Это значит:

- дата: 12.06.2026
- время: 20:00
- 3 команды
- по 6 игроков
- всего 18 мест
- цена 200 грн

Создавать игру можно только в группе. В личке бот откажет.

### Админское меню

```text
/game_settings
```

Открывает кнопки:

- `Открыть друзей`
- `Закрыть запись` / `Открыть запись`
- `Начать сбор оплат`
- `Отменить игру`

### Обновить сообщение игры

```text
/current_game
```

### Открыть друзей вручную

```text
/open_friends
```

### Закрыть запись

```text
/close_registration
```

После этого кнопка `Буду` отключается.

### Открыть запись обратно

```text
/open_registration
```

### Отменить игру

```text
/cancel_game
```

Можно указать причину:

```text
/cancel_game не набралось людей
```

После отмены кнопки записи отключаются.

### Изменить дату и время

```text
/edit_date 2026-06-19 20:00
```

### Изменить цену

```text
/edit_price 250
```

### Изменить количество команд

```text
/edit_teams 3
```

### Изменить игроков в команде

```text
/edit_players 7
```

После изменения формата бот пересчитывает лимит:

```text
max_players = teams_count * players_per_team
```

Первые по очереди становятся основным составом, остальные уходят в резерв.

### Запустить сбор оплат

```text
/payments
```

или

```text
/finish_game
```

## Основная логика

До 00:00 записываются только участники группы.

После 00:00, если основной состав не набран, бот открывает кнопку `Добавить друга`.

До 00:00 добавить друга нельзя даже если пользователь вручную нажмет старую inline-кнопку или остался в FSM-сценарии ввода имени.

Один участник может добавить максимум 3 друзей.

Добавленного друга можно отменить через кнопку `Отменить друга`. Бот покажет список только тех друзей, которых добавил именно этот участник.

Если основной состав заполнен, новые участники попадают в резерв.

Если кто-то нажал `Не буду`, первый игрок из резерва автоматически попадает в основной состав.

Если админ уменьшил лимит игроков, лишние участники из основного состава переходят в резерв по очереди записи.

Если админ увеличил лимит игроков, первые из резерва переходят в основной состав.

## Коллекции MongoDB

### users

Пользователи Telegram.

### games

Игры.

### participants

Участники игры: игроки и друзья.

### payments

Оплаты за игру.

## Важно

Бот использует polling, поэтому webhook не нужен.

Для продакшена можно заменить polling на webhook, но для MVP и закрытой футбольной группы polling проще.

## v3.8: тихое управление через личку

В группе теперь остается только основное сообщение игры. Админские действия не спамят чат.

### Как работает

1. Админ создает игру в группе:

```text
/new_game 2026-06-12 20:00 3 6 200 90 6
```

Бот удаляет команду и оставляет только карточку игры.

2. В карточке игры есть кнопка:

```text
⚙️ Управление
```

Если ее нажимает админ, бот отправляет меню управления в личку. Остальные участники этого не видят.

3. В личке доступны кнопки:

```text
📅 Дата
💰 Цена
👥 Команды
🏃 Игроки
👥 Открыть/закрыть друзей
🔒 Закрыть/открыть запись
💳 Начать сбор оплат
❌ Отменить игру
↩️ Вернуть игру
```

4. При изменениях бот обновляет только основное сообщение игры в группе.

### Важно

Админ и игроки должны хотя бы один раз написать боту `/start` в личке, иначе Telegram не даст боту первым отправить личное сообщение.

### Добавление друзей

Кнопка `Добавить друга` в группе открывает ввод имени в личке пользователя. В группе не появляются служебные сообщения `Введите имя друга`, `Друг добавлен` и т.д.


## v3.9 — исправления друзей и оплат

- Добавление друга теперь работает после переноса ввода имени в личку: pending-состояние хранится по `telegram_id` пользователя.
- При оплате в главном сообщении есть кнопка `👥 Оплата друзей`.
- Участник может отметить оплату или `не играл` для своих друзей.
- Админ также может менять статус оплаты друга.
- Основное сообщение игры обновляется и показывает статус оплаты напротив каждого участника.

## v4.0: Мультигрупповая рассылка и синхронизация в реальном времени

- **Создание игры из лички**: админ может запустить `/new_game` прямо в личных сообщениях с ботом.
- **Интерактивная рассылка**: после создания бот показывает список всех групп бота с кнопками `➕ Опубликовать` или `📢 Опубликовать во всех`.
- **Синхронизация состава**: при записи (`✅ Буду` / `❌ Не буду`) или добавлении друга в любой из групп карточки обновляются во всех связанных группах одновременно через параллельный `asyncio.gather`.
- **Управление группами**: в админском меню доступна кнопка `📢 Публикация в группах` для добавления игры в новые чаты или отзыва карточки из ненужных чатов.
- **Автоматический реестр групп**: коллекция `chats` автоматически отслеживает группы, в которых состоит бот.
- **Бесшовный ввод друзей**: если участник нажал кнопку добавления друга в группе, но ещё не запускал бота, бот запоминает действие и сразу при нажатии `/start` в личке предлагает ввести имя друга (без повторного нажатия в группе).

## v4.1: Короткое создание `/new_game`, динамический формат и расчет аренды

- **Короткий формат создания**: `/new_game YYYY-MM-DD HH:MM` (например, `/new_game 2026-11-06 19:00`). Дефолты (15 мест, 600 грн/час, 90 мин) выставляются автоматически.
- **Динамический формат состава**: карточка игры автоматически определяет формат под число записавшихся (до 9 чел — сбор; 10 чел — 2 команды 5х5; 11–12 чел — 5х5 с заменами; 13–14 чел — 3 команды с ротацией; 15 чел — 3 команды 5х5).
- **Чистый текст карточки**: убраны технические строки о друзьях из текста сообщения. Кнопки добавления друзей появляются на клавиатуре, когда набор друзей открыт.
- **Интерактивный расчет аренды поля**: при сборе оплат админ выбирает длительность (1.5 ч — 900 грн или 2.0 ч — 1200 грн), и бот сам делит сумму аренды поровну на всех игроков основы.
